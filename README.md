# Employee Attrition Prediction 🧑‍💼

This project predicts attrition risk using machine learning. Includes the training script, final trained model, and a Streamlit app for easy predictions.

## Key Files
- `model_training.py`: Full ML pipeline & training code
- `app.py`: Streamlit prediction web app
- `Employee.csv`: Sample dataset
- `employee_model.pkl`, `feature_names.pkl`: Saved model and feature list
- `requirements.txt`: Python dependencies
